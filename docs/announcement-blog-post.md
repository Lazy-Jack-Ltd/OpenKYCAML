# Introducing OpenKYCAML: The Open Hybrid KYC/AML Data Standard That Ends Fragmentation

**One payload. Full interoperability. AMLR-ready today.**

For years, financial institutions, VASPs, payment providers, and KYC utilities have struggled with the same painful reality: **KYC/AML data is locked in proprietary formats**.

Today, that changes.

**OpenKYCAML** is the world’s first neutral, open-source hybrid KYC/AML data standard that combines:
- **IVMS 101** (the de-facto Travel Rule standard)
- **eIDAS 2.0 / W3C Verifiable Credentials** (with SD-JWT support)
- **Full KYC monitoring & risk classifications** (customer risk rating, PEP status, sanctions screening, adverse media, beneficial ownership, review cycles, EDD flags, and more)

All in **one backward-compatible JSON Schema**.

### Why OpenKYCAML Exists
The regulatory landscape is converging fast:
- **AMLR** (EU Regulation 2024/1624) goes live in July 2027…
- **FATF Recommendation 16** and **ISO 20022**…
- **EUDI Wallets** will become the default high-assurance channel.

OpenKYCAML closes the gap that no other open standard has bridged.
